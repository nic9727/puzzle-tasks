# 拼图 · 把小事拼成一幅画

一个拼图式待办清单。写下一件件小事，每完成一件就点亮一块拼图，当所有小块都被点亮，一幅完整的图案会自己长出来。

不用一次看清全貌，先点亮眼前这一块就好。

## 在线体验

打开即用，手机和电脑浏览器都支持：

https://nic9727.github.io/puzzle-tasks/

## 功能特性

- 把待办事项做成一块块拼图，完成一件、点亮一块
- 顶部进度条和计数实时显示完成情况，例如 `2 / 9`
- 支持扩展拼图规模，从 2×2 一直扩展到 6×6（最多 36 件小事）
- 内置 4 幅图案，可随时切换
- 全部完成时弹出完成横幅、撒彩带庆祝，并记录完成日期
- 数据自动保存在本机浏览器，刷新页面不会丢失
- 单文件、零依赖、无需联网和后端，离线也能打开
- 自适应手机和电脑屏幕，支持触摸操作

## 怎么玩

1. 点击任意一块拼图，写下眼前能做的一小步，例如「打开文档写标题」
2. 做完后点击这块拼图上的「✓ 完成了」，小块翻面，露出图案的一角
3. 重复以上步骤，逐块点亮
4. 想安排更多事情，点「扩展拼图」增加格子
5. 点「换一幅图案」可以切换想拼出的画面
6. 全部点亮后会看到完整图案和庆祝动画，点「开启下一幅」重新开始

如果某件事标记错了，把鼠标移到已完成的小块上（手机上点一下小块），会出现「↩ 撤销」。

## 技术实现

- 纯原生 HTML / CSS / JavaScript，没有任何第三方库和框架
- 使用 Canvas 2D 程序化生成 1200×1200 的图案
- 使用 SVG `clipPath` 绘制带凹凸卡扣的真实拼图块形状
- 使用 `localStorage` 在本地持久化任务和完成状态
- 响应式布局，适配移动端和桌面端

整个应用只有一个 `index.html`，样式和脚本全部内联，双击即可在浏览器打开。

## 本地运行

无需安装任何环境，直接用浏览器打开 `index.html` 即可。

如果希望通过本地服务访问，可在文件所在目录运行：

```bash
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库
2. 上传 `index.html` 到仓库根目录
3. 进入仓库 `Settings` → `Pages`
4. 在 `Build and deployment` 中把分支选为 `main`、目录选为 `/ (root)`，保存
5. 等待一两分钟，即可通过 `https://用户名.github.io/仓库名/` 访问

## 数据与隐私

- 所有任务内容只保存在你当前设备浏览器的 `localStorage` 中，不会上传到任何服务器
- 不同设备、不同浏览器之间的数据相互独立，不会同步
- 清除浏览器数据会同时清空已保存的任务，请留意
